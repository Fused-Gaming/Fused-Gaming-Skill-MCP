⚡ Quick Start

Initialize the MCP Server

npm install npm run build npm start

Generate & View Registry

npm run registry:generate npm run registry:view

Load a Specific Skill

npm run skill:load -- underworld-writer-skill npm run skill:load -- canvas-design

Environment Setup

export NODE_ENV=production export DEBUG=false export LOG_LEVEL=info

💡 Pro Tips & Best Practices

✨ Tip 1: Combine Skills Strategically

Use multiple skills together for maximum impact. Example: Design with Canvas → Build with Frontend Design → Document with Storybook

⚡ Tip 2: Leverage Batch Operations

Use project-manager-skill to orchestrate complex workflows involving multiple skills simultaneously

📊 Tip 3: Monitor Progress in Real-Time

Keep project-status-tool open to track metrics and performance as you work

🚀 Tip 4: Cache Optimization

Enable caching in configuration for frequently used skills to improve performance

🔄 Tip 5: Keep Skills Updated

Run npm update --workspace regularly to get latest versions with bug fixes and features

🎯 Tip 6: Use Registry for Discovery

When unsure what to use, check /registry/REGISTRY.md for complete inventory and descriptions

💾 Tip 7: Automate with SyncPulse

Use SyncPulse for multi-agent workflows to coordinate complex tasks across multiple skills

🔐 Tip 8: Environment Variables

Use environment variables for sensitive config: NODE_ENV, API keys, logging levels
