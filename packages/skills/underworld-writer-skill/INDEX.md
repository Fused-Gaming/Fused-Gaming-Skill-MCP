## 🎯 Common Workflows

### Starting a Fiction Project

1. Read [`SKILL.md`](./SKILL.md) (main skill overview)
2. Read [`use-cases/fiction/METHODOLOGY.md`](./use-cases/fiction/METHODOLOGY.md) (fiction-specific)
3. Reference [`shared/character-template.md`](./shared/character-template.md) (character profiles)
4. Build using Phase 1 → Phase 2 → Phase 3
5. Structure narrative with [`shared/narrative-architecture.md`](./shared/narrative-architecture.md)
6. Audit with [`shared/editorial-checklist.md`](./shared/editorial-checklist.md)

### Starting a True Crime Project

1. Read [`SKILL.md`](./SKILL.md) (main skill overview)
2. Read [`use-cases/true-crime/protocols/SKILL.md`](./use-cases/true-crime/protocols/SKILL.md) (true crime-specific)
3. Classify claims with [`verification-engine.md`](./use-cases/true-crime/protocols/verification-engine.md)
4. Construct queries with [`query-construction-guide.md`](./use-cases/true-crime/protocols/query-construction-guide.md)
5. Reconcile conflicts with [`cross-source-reconciliation.md`](./use-cases/true-crime/protocols/cross-source-reconciliation.md)
6. Escalate gaps with [`escalation-protocols.md`](./use-cases/true-crime/protocols/escalation-protocols.md)
7. Structure with [`shared/narrative-architecture.md`](./shared/narrative-architecture.md)
8. Use [`shared/character-template.md`](./shared/character-template.md) for cite-as-you-write
9. Audit with [`shared/editorial-checklist.md`](./shared/editorial-checklist.md)
10. Finalize with [`shared/author-note-conventions.md`](./shared/author-note-conventions.md)
