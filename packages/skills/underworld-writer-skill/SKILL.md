# Underworld Writer Skill

## Overview

The Underworld Writer Skill is a comprehensive system for crafting narratives that explore hidden worlds, criminal enterprises, shadowy organizations, and underworld themes. It provides **two complementary methodologies**:

1. **Fiction Methodology** - For creating supernatural underworld characters and worlds
2. **True Crime Methodology** - For writing factually sourced criminal narratives grounded in court records and primary sources

## Quick Navigation

**Choose your path:**

### 🎭 Writing Fictional Underworld Stories?
→ See [`./use-cases/fiction/METHODOLOGY.md`](./use-cases/fiction/METHODOLOGY.md)

- Building mythological underworld narratives (vampires, demons, supernatural hierarchies)
- Creating fictional organized crime narratives (mafia families, gang structures)
- Developing character-driven underworld fiction with invented scenarios
- Building fantasy world systems with underworld elements

### 📚 Writing True Crime Narratives?
→ See [`./use-cases/true-crime/protocols/`](./use-cases/true-crime/protocols/) and start with [`SKILL.md`](./use-cases/true-crime/protocols/SKILL.md)

Use when:
- Writing long-form true crime grounded in court records and primary sources
- Structuring chapters around verified events without inventing dialogue
- Auditing claims by source tier (court records → journalism → secondary sources)
- Escalating unverified claims through PACER, BOP records, and investigative protocols

## Tools & Workflows

### For Fiction Writers

**Phase 1: Character Foundation**
- Establish core identity, origin, physical characteristics
- Develop background and core motivation

**Phase 2: Underworld Integration**
- Define role, rank, faction affiliation
- Establish powers, abilities, relationships, and resources

**Phase 3: Narrative Architecture**
- Connect to mythological frameworks
- Map hierarchies and conflicts
- Develop story arc and thematic elements

### For True Crime Writers

**Step 1: Source-Tier Triage**
- Use [`./use-cases/true-crime/protocols/verification-engine.md`](./use-cases/true-crime/protocols/verification-engine.md)
- Classify claims by evidence quality (Tier 1: legal record → Tier 4: marketing copy)

**Step 2: Query Construction**
- Apply [`./use-cases/true-crime/protocols/query-construction-guide.md`](./use-cases/true-crime/protocols/query-construction-guide.md)
- Build specialized search patterns for subject-heavy cases

**Step 3: Cross-Source Reconciliation**
- Resolve conflicts using [`./use-cases/true-crime/protocols/cross-source-reconciliation.md`](./use-cases/true-crime/protocols/cross-source-reconciliation.md)
- Count independent verification lines

**Step 4: Escalation Protocols**
- Resolve gaps using [`./use-cases/true-crime/protocols/escalation-protocols.md`](./use-cases/true-crime/protocols/escalation-protocols.md)
- Access PACER, BOP, archive, and primary source strategies

**Step 5: Structure Narrative**
- Apply scene-by-scene sourcing outline with tier attribution
- Use [`shared/narrative-architecture.md`](./shared/narrative-architecture.md)

**Step 6: Audit & Polish**
- Run through [`shared/editorial-checklist.md`](./shared/editorial-checklist.md)

## Core Principles

### Shared Across Both Methodologies

1. **Systematic Development** - Build narratives through structured phases
2. **Consistency** - Ensure all elements align and support each other
3. **Transparency** - Disclose editorial decisions and limitations
4. **Depth** - Develop characters, relationships, and world systems thoroughly
5. **Integration** - Connect elements into cohesive narratives

### Fiction-Specific

- **Believability within constraints** - Make character choices inevitable given world rules
- **Thematic resonance** - Connect character arcs to larger symbolic meanings
- **Hierarchical complexity** - Build multi-level power structures

### True Crime-Specific

- **Tier-ranked sourcing** - Never treat repetition as corroboration
- **Primary-source priority** - Legal records and direct interviews over paraphrased profiles
- **No invention** - Dialogue, specific dates, and interior thoughts are flagged or excluded without sources
- **Editorial honesty** - Dramatized reconstruction is labeled; narrative choices are auditable

## Success Criteria

### For Fiction
- All three phases comprehensively developed
- Character feels integrated into underworld setting
- Clear motivation and conflict points established
- Consistent with broader mythology and lore
- Detailed enough for narrative development

### For True Crime
- All claims have verified source tiers
- Unresolved gaps are disclosed in author's note
- Sourcing is auditable throughout
- No invented dialogue or interior monologue without disclosure
- Editorial decisions are transparent and justified
